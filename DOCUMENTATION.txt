Documentation du Programme GPS du Lycée

Introduction:
Ce programme est un système de navigation intérieure pour le lycée. Il permet aux utilisateurs de se repérer dans les différents bâtiments (A et B) et de trouver leur chemin vers les salles de classe. Le programme utilise Pygame pour l'interface graphique et implémente l'algorithme de Dijkstra pour le calcul des itinéraires.


Écrans du Programme

1. Écran d'Accueil
L'écran d'accueil affiche :
- Titre "GPS CIV" : Le nom de l'application en grand
- Bouton "ITINÉRAIRE" : Permet d'accéder à la carte de navigation
- Bouton "DOCUMENTATION" : Affiche cette documentation

2. Écran Itinéraire
C'est l'écran principal de navigation contenant :
- La carte interactive du lycée
- Les menus de sélection
- Les boutons de navigation
- Les informations sur les salles


Boutons et Fonctionnalités

Navigation entre les étages :
- ↑ (Flèche haut): Monter d'un étage 
- ↓ (Flèche bas) : Descendre d'un étage 
- -> (Suivant) : Passer à l'étage suivant dans le parcour suivi
- <- (Précédent) : Revenir à l'étage précédent dans le parcour suivi

- Raccourci clavier : Touches ↑/↓ pour changer d'étage.

 Sélection des bâtiments :
- Bâtiment A : Affiche le bâtiment A
- Bâtiment B : Affiche le bâtiment B

Ces boutons permettent de basculer entre les deux bâtiments du lycée sur l'étage A100/B100

Menu Déroulant des Salles

Le menu déroulant en haut à gauche permet de sélectionner :
- L'étage : Bâtiment A (3ème, 2ème, 1er, RDC) ou Bâtiment B (3ème, 2ème, 1er)
- La salle de destination : Liste des salles disponibles sur l'étage sélectionné

Sous-options par étage :
Bâtiment A :
- 3ème étage : A301 à A310
- 2ème étage : A201 à A211
- 1er étage : A102 à A106
- RDC : A001 à A014

Bâtiment B :
- 3ème étage : B311 à B325
- 2ème étage : B214 à B223
- 1er étage : B111 à B118

Menu des matières :
Le menu déroulant en haut au centre permet de sélectionner une matière pour afficher les informations de cours

Boutons d'Information :
Loupe : Affiche les points d'intérêt sur la carte
Salles : Affiche les boutons de toutes les salles sur la carte

Modes de calcul :
Le programme propose plusieurs modes de calcul d'itinéraire :
- Mode normal : Calcul du chemin le plus court
- Mode calories : Estimation des calories brûlées
- Mode temps : Estimation du temps de trajet

Affichage des étages
Les cartes sont organisées par étage :
- Étage 1 : RDC du bâtiment A et CDI
- Étage 2 : 1er étage du bâtiment B
- Étage 3 : 1er étage du bâtiment A
- Étage 4 : 2ème étage bâtiments A et B
- Étage 5 : 3ème étage bâtiments A et B

Légende :
- Vert foncé : chemin à suivre
- Jaune : salles de départ/arrivée et escaliers (les escaliers sont reconnaissables car ils n’ont pas de nom lorsqu’on affiche le nom des salles)
