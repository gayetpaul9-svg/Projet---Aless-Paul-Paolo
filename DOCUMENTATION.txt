# Documentation du Programme GPS du Lycée

## Introduction

Ce programme est un système de navigation intérieure pour le lycée. Il permet aux utilisateurs de se repérer dans les différents bâtiments (A et B) et de trouver leur chemin vers les salles de classe. Le programme utilise Pygame pour l'interface graphique et implémente l'algorithme de Dijkstra pour le calcul des itinéraires.

---

## Structure du Programme

Le programme est composé de plusieurs modules :

| Fichier | Fonction |
|---------|----------|
| `main.py` | Point d'entrée principal, boucle Pygame, gestion des événements |
| `algo.py` | Algorithme de Dijkstra et graphe du lycée |
| `classes.py` | Classes d'interface (Button, Dropdown) |
| `fonctions.py` | Fonctions utilitaires (GPS, infos cours, calculs) |
| `layers.py` | Gestion des calques de cartes |
| `data_cours.py` | Données des cours et messages pédagogiques |

## Saisie de Texte

### Recherche de Salle

Pour rechercher une salle spécifique :
1. Cliquer sur le champ de saisie
2. Taper le nom de la salle (ex: "A301")
3. Appuyer sur **Entrée** pour valider

> **Fonction** : La fonction `infos_cours` retourne les informations sur les cours pour la salle recherchée.

### Navigation au Clavier

| Touche | Fonction |
|--------|----------|
| **Échap** | Retour à l'écran d'accueil ou quitter |
| **↑** | Monter d'un étage |
| **↓** | Descendre d'un étage |
| **Retour arrière** | Supprimer le dernier caractère lors de la saisie |
| **Entrée** | Valider la saisie de texte |

## Fonctionnalités Avancées

### Algorithme de Dijkstra

Le programme utilise l'algorithme de Dijkstra pour calculer le chemin le plus court entre deux salles. Le graphe est défini dans `algo.py` avec :
- **Sommets** : Les salles et couloirs du lycée
- **Arêtes** : Les déplacements possibles entre les pièces
- **Poids** : Le temps de déplacement (1 pour chaque déplacement)

### Modes de Calcul

Le programme propose plusieurs modes de calcul d'itinéraire :
- **Mode normal** : Calcul du chemin le plus court
- **Mode long** : Calcul d'un chemin passant par un étage éloigné
- **Mode calories** : Estimation des calories brûlées
- **Mode temps** : Estimation du temps de trajet

### Affichage des Étages

Les cartes sont organisées par étage :
- **Étage 1** : RDC du bâtiment A
- **Étage 2** : 1er étage du bâtiment B
- **Étage 3** : 1er étage du bâtiment A
- **Étage 4** : 2ème étage bâtiments A et B
- **Étage 5** : 3ème étage bâtiments A et B

## Variables d'État Principales

Le programme utilise les variables suivantes pour gérer son état :

| Variable | Description |
|----------|-------------|
| `etat` | "accueil" ou "itinéraire" |
| `etage` | Étage actuel (1 à 5) |
| `batiment_selectionne` | "A" ou "B" |
| `afficher` | Affiche/masque la loupe |
| `afficher_s` | Affiche/masque les salles |
| `menu_ouvert` | Menu déroulant ouvert/fermé |
| `saisie_active` | Mode saisie texte actif |

## Contrôle de la Souris

- **Molette** : Faire défiler les menus déroulants
- **Clic gauche** : Sélectionner un élément, valider un choix
- **Survol** : Les boutons changent de couleur au survol (gris plus foncé)

---

## Messages Pédagogiques

Le programme affiche des messages pédagogiques en fonction de la matière sélectionnée. Ces messages sont définis dans `data_cours.py` et varient selon les cours.

---

## Résumé des Interactions

1. **Démarrage** → Écran d'accueil avec musique
2. **Clic sur "ITINÉRAIRE"** → Accès à la carte de navigation
3. **Sélection d'un étage** → La carte correspondante s'affiche
4. **Sélection d'une salle** → Calcul et affichage du chemin
5. **Utilisation de la loupe** → Affichage des points d'intérêt
6. **Sélection d'une matière** → Affichage des infos de cours
7. **Clic sur Échap** → Retour à l'accueil ou quitter
